Honeycomb is a tool for exporting from Swarm Engine games, it's confirmed working on Toxic Commando and WWZ. Unfortunately I am unlikely to work further on this tool as I have other stuff, it was thrown quickly together for a buddy.

If you want to contribute to the repo let me know, feel free to fork and PR, issues can be logged but won't be looked at by me.
